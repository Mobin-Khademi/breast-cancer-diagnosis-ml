# Breast Cancer Diagnosis Classification (WDBC)

A machine learning project that classifies breast tumors as **benign** or **malignant** using the Wisconsin Diagnostic Breast Cancer (WDBC) dataset. Three tree-based models are tuned with cross-validated grid search and compared; the best one (Random Forest) is trained as the final model and saved to disk.

> ⚠️ **Disclaimer:** This is an educational project. It is not a medical device and must not be used for real clinical decisions.

## Dataset

- **Source:** [UCI Machine Learning Repository – Breast Cancer Wisconsin (Diagnostic)](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic)
- **Samples:** 569 (357 benign – 62.7%, 212 malignant – 37.3%)
- **Features:** 30 numeric features computed from digitized images of fine needle aspirates (FNA) of breast masses. For each of 10 cell-nucleus characteristics (radius, texture, perimeter, area, smoothness, compactness, concavity, concave points, symmetry, fractal dimension), the **mean**, **standard error**, and **worst** (largest) value are recorded.
- **Target:** `diagnosis` — `M` (malignant) → 1, `B` (benign) → 0

## Workflow

1. Load `wdbc.data` and assign column names
2. Encode the target (`M` → 1, `B` → 0) and drop the `id` column
3. Inspect class balance
4. Stratified 80/20 train/test split (`random_state=42`) → 455 train / 114 test
5. Tune three models with `GridSearchCV` (5-fold CV, scoring = F1, `class_weight="balanced"` where supported):
   - Decision Tree
   - Random Forest
   - Gradient Boosting
6. Compare models on the held-out test set (accuracy, precision, recall, F1, ROC curves)
7. Retrain the best model (Random Forest), evaluate it in detail, plot feature importances
8. Save the model with `joblib`

## Results (test set, 114 samples)

| Model             | Accuracy | Precision | Recall | F1     |
|-------------------|----------|-----------|--------|--------|
| Random Forest     | 0.9649   | 0.9750    | 0.9286 | 0.9512 |
| Gradient Boosting | 0.9649   | 1.0000    | 0.9048 | 0.9500 |
| Decision Tree     | 0.9211   | 0.9714    | 0.8095 | 0.8831 |

**Final model: Random Forest** — ROC AUC = **0.9970**

Best hyperparameters: `n_estimators=100`, `max_depth=None`, `min_samples_split=5`, `min_samples_leaf=2`

## Notes and limitations

- The test set is small (114 samples), so the difference between Random Forest and Gradient Boosting (a single sample) is not statistically meaningful.
- Many features are highly correlated (e.g. radius, perimeter, area), so feature importance is shared among them and should be interpreted with care.
- In a medical setting, missing a malignant case (false negative) is costlier than a false alarm. Decision-threshold tuning to favor recall would be a natural next step.
- A single train/test split was used; repeated or nested cross-validation would give a more robust estimate.
